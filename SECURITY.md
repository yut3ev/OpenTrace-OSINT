# Security Policy

Do not report secrets or personal data in public issues. For vulnerabilities, contact the repository maintainers privately using the contact configured in the GitHub Security tab.

Supported scope: application vulnerabilities, SSRF, injection, XSS, CSV injection, secret leakage, authorization issues and denial-of-service risks.

This project is intended for public-data research and authorized investigations only. Do not submit features that bypass access controls or expose private information.
